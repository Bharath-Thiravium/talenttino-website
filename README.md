# Talentteno Institute

Clean project layout with separate frontend, backend, and database folders.

## Folder Structure

```text
talentteno/
├── frontend/              Public website pages, assets, uploads
├── backend/               PHP admin panel, DB config, optional Node API
│   ├── admin/             Admin panel pages
│   ├── includes/          Shared PHP backend config
│   └── node/              Node.js + MySQL API
├── database/              MySQL schema and seed data
│   └── database_setup.sql
└── README.md
```

## Run PHP Website

```bash
php -S 127.0.0.1:8000
```

For media uploads up to 100 MB, start the local PHP server with matching upload limits:

```bash
php -d upload_max_filesize=100M -d post_max_size=110M -S 127.0.0.1:8000
```

Open:

- Frontend: `http://127.0.0.1:8000/frontend/index.php`
- Admin: `http://127.0.0.1:8000/backend/admin/login.php`

Default admin:

- Username: `admin`
- Password: `password`

## Database

Create and import for local development:

```bash
chmod +x database/setup_local_mysql.sh
database/setup_local_mysql.sh
```

On XAMPP, start MySQL from XAMPP first. The setup script will use `/opt/lampp/bin/mysql` automatically when it is available.

DB settings are in:

```text
backend/includes/db.php
```

You can also use environment variables:

```text
DB_HOST
DB_PORT
DB_USER
DB_PASS or DB_PASSWORD
DB_NAME
DB_SOCKET
```

Default local development credentials:

```text
DB_USER=talentteno_app
DB_PASS=talentteno_local_password
DB_NAME=talentteno_db
```

## Run Node Backend

```bash
cd backend/node
npm install
npm run start
```

Node API:

```text
http://127.0.0.1:5000/api/health
```

## Notes

- `database/runtime/` is local MySQL generated data and should not be committed.
- `backend/node/node_modules/` is generated by `npm install`.
- Public brochure uploads belong in `frontend/uploads/brochures/`.


Branch:

```text
main
```

Remote:

```text
https://github.com/Bharath-Thiravium/talenttino-website.git
```

Live URL:

```text
https://talenttino.athenas.co.in/ergon/
```

`git commit` updates local Git history. `git push` updates GitHub. `git push` alone does not necessarily update the live hosting server. The live hosting account must pull or deploy the new commit before visitors see the change.

Browser cache can still show older CSS, JavaScript, or logo files. Public pages now print a hidden source marker:

```text
TT_DEPLOY_VERSION
```

Use View Source to confirm the deployed marker matches the GitHub commit.

cPanel deployment steps:

1. Open cPanel.
2. Open Git Version Control.
3. Select the Talenttino repository.
4. Click Manage.
5. Click Update from Remote.
6. Click Deploy HEAD Commit.
7. Open the live website.
8. Hard refresh using Ctrl + Shift + R.
9. Open View Source.
10. Search for `TT_DEPLOY_VERSION`.
11. Confirm the live commit matches GitHub.

Common manual upload paths, which must be verified in hosting before use:

```text
public_html/ergon/
public_html/ergon/frontend/
public_html/ergon/admin/
public_html/ergon/api/
public_html/ergon/backend/
```

For scripted deployment from this repository, use a verified hosting path:

```bash
LIVE_ROOT=/home/ACCOUNT/public_html/ergon ./deploy-live.sh
```

The deployment script refuses to guess `LIVE_ROOT`, refuses dangerous destinations, checks that local `main` matches `origin/main`, creates a timestamped backup, preserves `.env`, preserves uploads, and preserves `backend/includes/db.php`.
